# Zentrales medizinisches Vokabular fuer DicDoc
#
# Diese Datei wird von jeder DicDoc-Installation beim Start automatisch
# abgerufen: neue Begriffe hier werden lokal ergaenzt (nur lesend/einseitig -
# lokale Aenderungen einzelner PCs werden NICHT hierher zurueckgeschrieben).
#
# Um einen Begriff fuer ALLE Praxis-PCs verfuegbar zu machen: hier ueber den
# Stift/Edit-Button auf GitHub eine Zeile hinzufuegen und committen.
#
# Ein Begriff pro Zeile. Zeilen mit "#" sind Kommentare und werden ignoriert.
#
# Bewusst leer: nur Begriffe eintragen, die in der Praxis tatsaechlich falsch
# erkannt werden - nicht vorab moeglichst viele. Fuer einzelne bekannte
# Verwechslungen (z.B. "Rechtsmatogen" statt "Rhegmatogen") eignet sich in der
# App die Korrekturen-Verwaltung oft besser, da sie kein Token-Budget hat.
#
# WICHTIG - gemessene harte Grenze: Whisper beruecksichtigt vom Prompt nur die
# LETZTEN ca. 223 Tokens, der Rest wird vorne stillschweigend abgeschnitten.
# Liste kompakt halten und mit dem echten Tokenizer nachmessen, nicht einfach
# nach Zeichenzahl schaetzen.
